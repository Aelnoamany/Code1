الكود المصري لأسس التصميم واشتراطات التنفيذ لحماية المنشآت من أخطار الحريق – الجزء الثالث

| |
| :--- |
| هل هناك توصيلات غير محكمة (Loose Connections) وهي التي تسبب شرر كهربي (Sparking/Arcing)؟ |
| **ثالثًا: أجهزة الحماية (القواطع والفيوزات)** |
| يوجد قاطع رئيسي مناسب لسعة التيار القصوى لكل لوحة. |
| كل دائرة فرعية (إنارة/ مخارج/ أحمال خاصة) لها قاطع أو فيوز مستقل وبسعة مناسبة لمقطع الكابل. |
| تم التأكد من أن تيار القاطع أقل من تيار تحمّل الكابل (لا يوجد كابل أقل من القاطع). |
| تم تركيب حمايات التسرب الأرضي (RCD/ELCB) في الدوائر المطلوبة (خاصة المخارج، الحمامات، المطابخ، ... إلخ). |
| يوجد تنسيق (Selectivity) بين القواطع الرئيسية والفرعية. |
| هل تم التأكد من عدم وجود تحايل أو تجاوز لأنظمة الحماية؟ |
| **رابعًا: لوحات التوزيع** |
| لوحة إنذار الحريق (Fire Alarm Panel) لها تغذية مستقلة ومؤمنة، مع خط بطاريات احتياطية كما بالكود. |
| يوجد نظام إطفاء موضعي داخل اللوحة الرئيسية (غاز نظيف/ Aerosol / أنبوب حراري ... إلخ) معتمد. |
| تم التأكد من أن اللوحات لا تسخن بشكلٍ غير طبيعي أثناء التشغيل (لا توجد آثار اسمرار أو رائحة احتراق). |
| جميع اللوحات مغلقة بأبواب سليمة، مزودة بأقفال أو وسائل منع العبث. |
| تم تثبيت اللوحات جيدًا، والأبواب تفتح في اتجاه آمن وبدون عوائق. |
| لا توجد آثار احتراق أو تغيُّر لون على العوازل أو البارات النحاسية. |
