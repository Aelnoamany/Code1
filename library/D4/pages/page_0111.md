الكود المصري لأسس التصميم واشتراطات التنفيذ لحماية المنشآت من أخطار الحريق - الجزء الثالث

محطات المترو والقطارات، الأنفاق المدارس والجامعات والمباني التعليمية الكبيرة المباني الصناعية أو المخازن ذات الخطورة العالية.

### ٣-٤ أنظمة الكشف والإنذار طبقًا لتصنيف الإشغال:

#### ١-٣-٤ إشغال تجمعات الأفراد (أ):

| إشغال تجمعات الأفراد: مجموعات فرعية (أ-١ / أ-٢ / أ-٣ / أ-٤): |
| :--- | :--- |
| **الكشف والإنذار** | - يجب توفير نظام كشف وإنذار تلقائي معنون لتغطية كامل فراغات المبنى بما فيه الفراغات القابلة للتأجير (Core & Shell Spaces).<br>- في حالة الفراغات القابلة للتأجير يجوز توفير وحدة ربط معنونة مع النظام الأساسي للمبنى لكل فراغ وفي هذه الحالة يجوز استخدام نظام كشف وإنذار من النوع التقليدي داخل الفراغ مع ربطه بوحدة الربط المعنونة لضمان تغطية جميع الفراغات. |
| **التنبيه** | - يجب توفير نظام تنبيه مسموع ومرئي داخل المبنى.<br>- يجب توفير نظام إخلاء صوتي يسمح بإذاعة رسائل التنبيه/ الإخلاء سواءً مسجلة أو عن طريق النداء. |
| **إشغال تجمعات الأفراد: مجموعة فرعية (أ-٥): (تسري الاشتراطات التالية على المباني المحيزة المغلقة في الهواء الطلق)** |
| **الكشف والإنذار** | - يجب توفير نظام كشف وإنذار تلقائي (معنون أو تقليدي) بكل مبنى مع ربط الأنظمة ببعضها. |
| **التنبيه** | - يجب توفير نظام تنبيه مسموع ومرئي (إخلاء صوتي). |

#### ٢-٣-٤ إشغالات مؤسسية (ب):

| إشغالات مؤسسية: مجموعات فرعية (ب-١ / ب-٣ / ب-٤) |
| :--- | :--- |
| **الكشف والإنذار** | - يتم توفير نظام كشف وإنذار تلقائي معنون لتغطية كامل فراغات المبنى. |
| **التنبيه** | - يجب توفير نظام تنبيه مرئي في أماكن تواجد الأفراد غير القادرين على الحركة. |
