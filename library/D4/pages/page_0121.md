الكود المصري لأسس التصميم واشتراطات التنفيذ لحماية المنشآت من أخطار الحريق - الجزء الثالث

---

| هل تم استخدام أسلاك وكابلات ذات سعة تيار مناسبة للأحمال؟ |  |
| :--- | :--- |
| في مخارج الطوارئ، الكابلات المغذية للإضاءة/ أنظمة الحريق ذات نوع مقاوم للحريق ومحمية وفق المتطلبات. |  |
| لا توجد كابلات مكشوفة تمر في أماكن يمكن أن تتعرض فيها للصدمات أو التلف الميكانيكي. |  |
| هل العزل سليم ولا توجد تشققات أو تقشير؟ |  |
| جميع الأطراف (Terminals) مثبتة بإحكام، ولا يوجد كابلات غير مضغوطة جيدًا. |  |
| هل تم تثبيت الأسلاك بشكلٍ آمن لمنع التلف الميكانيكي؟ |  |
| هل تم تجنب تجميع الكابلات بشكلٍ مفرط (لتفادي تراكم الحرارة)؟ |  |
| لا توجد كابلات مؤقتة/ ممدودة عشوائيًا خارج المسارات المعتمدة. |  |
| عدم وجود مصادر حرارة عالية ملاصقة للكابلات أو اللوحات (أفران، ومدافئ، ومواسير بخار ... إلخ). |  |
| تم تجنب تمرير الكابلات فوق حواف حادة أو أماكن يمكن أن تقطع الغلاف. |  |
| الكابلات المثبتة على الـ Trays أو الـ Ladders مربوطة جيدًا بمسافات مناسبة .(Cable ties / Clamps) |  |
| في المواسير (Conduits) ، لا توجد كسور أو فتحات غير مغلقة، وجميع الوصلات محكمة. |  |
| تم فصل كابلات القدرة عن كابلات الإشارة والاتصالات قدر الإمكان، أو استخدام فواصل معدنية في نفس الترنك. |  |
| توجد حواجز/بوكسات مناسبة عند اختراق الجدران والأسقف، مع حشو مانع للحريق .(Fire stopping) |  |
